## Preserved product behavior

The primary scenario is CampusConnect, with fictional Aarav, Riya, Neha and Kabir. The practice project is an isolated copy of the same scenario, not a new product direction. Communication imports are synthetic because real communication integration belongs to future scope in the proposal.

The proposal sometimes lists “Pending human review” alongside machine evidence labels. The requested prototype explicitly distinguishes these concepts, so the implementation uses separate evidence and review fields. Human verification adds a recorded resolution without rewriting historical evidence labels.
